# EONFOLK support

EONFOLK is pre-alpha software maintained on a best-effort basis. There is no
service-level commitment and no production deployment to operate.

## Where to ask

- Use the **Bug report** form for reproducible incorrect behavior.
- Use **Gameplay feedback** for confusion, boredom, attachment, or Chronicle
  clarity.
- Use **Accessibility or performance** for input, motion, semantic UI, device,
  frame-time, payload, or loading concerns.
- Use **Scoped feature proposal** for a player problem that existing behavior
  cannot solve.
- Follow [SECURITY.md](SECURITY.md) for potential vulnerabilities.

Search existing issues first. Include the commit or version, OS, browser,
viewport, steps, and the smallest safe evidence that reproduces the problem.

## Local data and diagnostics

World history and feedback reports remain in the current browser profile. Clear
site data only if you accept losing that local state. The project does not yet
provide backup, import, restore, or cloud recovery.

Diagnostic details are opt-in and local. Review any screenshot, trace, or copied
diagnostic text before sharing it. Remove names, tokens, file paths, account
identifiers, and unrelated browsing information.

## Not currently supported

Hosted worlds, accounts, multiplayer, payments, third-party model setup, custom
deployments, modified dependency stacks, and recovery of deleted browser data
are outside current support.
