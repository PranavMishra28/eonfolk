# Changelog

Notable player-facing and technical changes will be recorded here. The project
has not published a release.

## Unreleased — pre-alpha

### Added

- Release Genesis entry and a world-first local game route.
- One deterministic generated region with two settlements and eight citizens.
- Visible movement, needs, gathering, consumption, exchange, repair, projects,
  relationships, institutions, and social interaction.
- A sponsor path that supports intervention or abstention, independent
  acceptance, rejection, delay, or reinterpretation, and distinct later
  consequences.
- A factual Chronicle with typed causal relationships, allegation-versus-
  verification handling, replay context, and navigation back into the world.
- Versioned IndexedDB events and snapshots, controlled catch-up, deterministic
  replay, and fail-closed handling of unsupported saved data.
- A complete deterministic Standard Brain and an optional bounded local-model
  experiment that is not required to play.
- Keyboard and semantic alternatives for consequential actions, reduced-motion
  behavior, and a playable non-WebGL fallback.
- A read-only research surface and consented, browser-only feedback queue with no
  upload path.

### Security and reliability

- Closed typed commands, revision checks, atomic canonical transitions, and
  separation between Reality, beliefs, model proposals, diagnostics, and UI.
- Inert rendering and bounded validation for untrusted prose and structured
  proposals.
- Deterministic simulation, replay, property, fault-injection, formal-model,
  production-browser, network-egress, dependency, and secret checks.

### Known limitations

- This is not a public release and has not completed unfamiliar-player studies.
- Browser data has no backup, export, import, restore, or cloud recovery.
- Physical-phone performance, broad screen-reader coverage, thermals, and a
  twelve-citizen stress target remain unverified.
- There is no hosted canonical world, account, public multiplayer, payment,
  production deployment, or required external inference.
