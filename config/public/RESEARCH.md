# Research map

EONFOLK uses research to motivate bounded, testable contracts—not to claim that
simulated citizens reproduce human behavior. The root
[`references.bib`](../references.bib) file is the durable citation catalog.

## Primary research spine

| Area | Sources | Project use and limit |
|---|---|---|
| Agent memory and reflection | `park2023generative`, `sumers2024coala` | Motivates typed episodic, semantic, and social memory; prose never becomes authoritative truth |
| Embodied open-ended agents | `wang2023voyager` | Motivates compositional plans and environment feedback; executable code and external tool authority are rejected |
| Agent societies | `altera2024projectsid`, `piao2026agentsociety` | Establishes an active research area; does not validate EONFOLK's consumer loop or human fidelity |
| Deterministic task planning | `nau2003shop2` | Supports explicit hierarchical decomposition over actor-visible facts and legal affordances |
| Partial-observability planning | `silver2010pomcp` | Informs the boundary between visible decision context and hidden world facts |
| Formal specification | `lamport2002specifying` | Supports bounded model checking of high-value persistence invariants; it is not a proof of the whole game |

## Evidence language

- **Verified fact:** a claim supported by an opened primary or official source.
- **Inference:** a reasoned connection from evidence to this design.
- **Product hypothesis:** a proposition that needs executable or player evidence.
- **Unresolved:** an important uncertainty without sufficient evidence.

Add a reference only when it changes a decision, implementation contract, test,
benchmark, or explicit reopen condition. Prefer papers, standards, official
repositories, model cards, and official documentation.
