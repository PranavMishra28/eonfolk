# Intrinsic distribution and first-user path

**Purpose:** define the product's share object and no-paid evidence path to the first 10, 100, and 1,000 activated users.

**Status:** ACCEPTED AS POST-PROOF HYPOTHESIS — no publication or outreach is authorized

**Authority boundary:** this file owns distribution behavior and gates. [CHRONICLE](CHRONICLE.md) owns factual content; [distribution research](../research/DISTRIBUTION_RESEARCH.md) owns dated channel evidence; implementation/publication requires separate authorization.

**Related documents:** [product](PRODUCT.md), [human loop](HUMAN_LOOP.md), [world structure](WORLD_STRUCTURE.md), [competitors](../research/COMPETITORS.md)

## Owned decision

Distribution is a product test, not a posting calendar. An **activated user** resolves the first consequential intervention in a playable build. The V1 artifact is a factual **Story Card** rendered from accepted Chronicle events: recognizable person, sponsor advice, Mara's independent choice, three authoritative beats, and unresolved tension.

The slice builds only copyable text, a screenshot-ready layout, and deterministic replay controls already needed for QA. It does not build social APIs, video rendering, accounts, referral rewards, creator dashboards, analytics SDKs, or World Forks.

## Five-second / 20-second artifact

- **0–2 seconds:** “I advised Mara to expose the shortage.” Citizen and conflict are understandable without product knowledge.
- **2–12 seconds:** “Mara chose to verify” → statement triggered audit → audit/rule/relationship consequence, each from authoritative events.
- **12–20 seconds:** “What followed” plus unresolved relationship; a playable canonical URL appears only if later deployment is authorized.

The local artifact fails if three of five context-free viewers cannot answer who advised, who independently chose, what followed, and what remains unresolved within five seconds. This tests comprehension only—not click, acquisition, activation, or distribution. Model/provider branding is not the headline. No “sentient,” “alive,” or unsupported causal claim.

## First 10 / 100 / 1,000

| Stage | No-paid action | Gate before expansion |
|---|---|---|
| First 10 | 15–20 high-touch invitations across systemic-game players, life-sim/god-game players, AI-native skeptics, nontechnical observers, and creators; run observed 15-minute sessions; keep abandonment in denominator | 8/10 name citizen/motive; 7/10 reconstruct chain; 4/10 voluntary seven-day return; 2/10 copy artifact/seed |
| First 100 | Free no-sign-up browser page only after first gate; factual replays; one rules-compliant feedback/community post at a time; one substantive Show HN when directly playable; creator sessions and patron invitations are ordinary outreach, not partnerships | 60% intervention completion; 50% explain action; 30% return; 15% copy/share; one unaffiliated share yields an activated user |
| First 1,000 | Public Chronicle URLs only after hosting approval; weekly fixed seed, repeatable creator hooks, earned discussion in gaming/AI communities; repeat only channels that produced activation | If 5,000 qualified landings × 20% activation does not occur, report failure; no paid acquisition or growth infrastructure as compensation |

All thresholds are **PRODUCT HYPOTHESIS**, not forecasts or industry standards.

## Intrinsic share inventory

Later eligible events include betrayal, succession, institution longevity, election, revolution, famine-to-coup causality, and private World Fork results. Only betrayal/relationship consequence and a simple rule change are slice-feasible. Succession, election, revolution, coup, and World Fork require underlying implemented systems; presentation must never fake them.

## Channel variants

| Channel | Format | Product framing |
|---|---|---|
| X, Reddit, Discord, gaming communities | 16:9 or square, burned-in text, silent-comprehensible | actual consequence first; direct playable link; current community rules rechecked |
| TikTok/Reels/Shorts | 9:16, large safe-zone text, same 10–20-second beats | player judgment → citizen response → unresolved result |
| Hacker News | Direct factual interactive replay plus technical/product account of deterministic events, bounded cognition, and evidence requested | clip secondary; no sign-up, generated comments, vote solicitation, or benchmark hype |

The builder manually captures the running build. One responsive composition produces 16:9 and 9:16 evidence from the same facts; it is not separate art. V1 calls the action **Copy story card**, includes no dead link or unexplained seed jargon, and hides technical IDs under **Evidence**. A recipient route, CTA, platform-safe crop, and acquisition test are separate post-proof work requiring deployment/publication authority.

## Model-ecology consequence

Provider/model/version is retained in provenance when used, but never defines a citizen, competitive class, or normal onboarding choice. A viewer should care that Mara verified then disclosed, not whether a named model proposed it. Explicit model diversity is reopened only by blinded story/return tests that beat Standard Brain without creating benchmark behavior.

## Rejected alternatives

Reject paid acquisition, creator payments/required partnerships, referral schemes, email gates, account counts, impressions as users, mass cross-posting, posting bots, launch before comprehension, and polished cards that conceal trivial/random mechanics. Reject public Chronicle URLs in 001 because deployment is excluded.

## Reopen evidence

If personal Chronicles feel too private, share fixed public challenge seeds instead. If static cards outperform timed artifacts, cut video work. If no unaffiliated share produces activation by 100, stop 1,000-user work and revisit product pull/message. If distribution work becomes a second pipeline, reduce it to copy text plus OS screenshot.

## Remaining uncertainty

**UNRESOLVED:** organic conversion, channel fit, creator interest, and current moderation rules at publication time. **PRODUCT HYPOTHESIS:** causal artifacts travel because they expose human judgment and autonomous consequence.

## Resulting implementation behavior

Gate B provides a screenshot-ready Chronicle composition, **Copy story card**, deterministic rehearsal/reset for QA, and 16:9/9:16 responsive evidence for all three branches. This is private prototype evidence, not a share/activation claim. No posting integration, hosted URL, telemetry vendor, identity, partnership workflow, or media renderer enters 001.

## Constraint fit

The plan uses manual recruitment, existing accounts, free direct play only after authorization, and product artifacts already needed for return/QA. It assumes no spending, revenue, payment, proprietary data, regulated data, training, partnership, or enterprise motion.
