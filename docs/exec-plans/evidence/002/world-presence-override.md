## Binding requirements

- Riverhold must be a recognizable low-poly/stylized physical settlement with embodied humanoid citizens whose heads, torsos, arms, legs, locomotion, and visible work make the world understandable without a dashboard.
- Run a bounded PlayCanvas React architecture spike against Pixi before visual implementation. WebGL2 is the compatibility baseline; WebGPU is optional. Adopt PlayCanvas unless a measured material blocker exists.
- Preserve React/Vite and introduce a clean `WorldPresentation` / `SpatialProjection` boundary. Reality owns semantic action, origin, destination, timing, target, and result. Presentation owns interpolation and animation; renderer state never mutates Reality.
- Add coordinates/place anchors, entrances, interaction/work/rendezvous points, destinations, carried props, action durations, visual action states, navigation/pathing, blocked-geometry protection, collision/separation, and fixed-step/interpolated crowd movement. Evaluate Recast/Detour through `recast-navigation-js` and its PlayCanvas integration.
- Project every consequential canonical citizen action physically: walk, gather, exchange/transfer, communicate, repair and visible object change, and practical carried resources. Cosmetic river, smoke, mill, and vegetation motion must never imply false canonical state.
- Implement at least idle, walk, carry, gather, inspect, talk, listen, exchange, repair, eat/rest, and emotional-reaction animation states. Mara remains recognizable by silhouette/outfit without a giant marker.
- Retain an equivalent semantic DOM game. Recompose normal play so the physical world dominates and DOM is contextual support.
- Add deterministic temporal Living World checks proving movement, meaningful animation classes, canonical-event linkage, blocked-geometry/no-teleport behavior, and absence of display/Reality contradiction. Record spatial/animation mismatches through the Flight Recorder.
- Add a World Presence Gate: after ten seconds an unfamiliar observer recognizes a settlement, humanoid citizens, multiple activities, and one meaningful interaction/process; after thirty seconds they can describe several visible tasks without opening a dashboard.
- Founder Alpha cannot merge until the World Presence Gate, existing desktop/laptop/mobile performance profiles, semantic accessibility, and an independent visual/product reviewer answering **YES** to “Does Riverhold visibly feel inhabited and alive?” all pass. Failure is P1/release-blocking.
