## Byte-level determinism profile

Use determinism profile `eonfolk-determinism-v2`: integer simulation seconds; nonnegative int32 conserved quantities; checked signed-int32 scores and basis points; truncation toward zero; NFC normalization at ingress; RFC 8785 canonical JSON over a restricted integer-only domain; SHA-256; and scheduler order `(time, priority, actorId, localOrdinal)`.

Every JSON revision, event sequence, simulation time, draw counter, creation sequence, receipt revision, and fencing token is a `SafeU64`: a JSON number that is an integer in inclusive range `0..9007199254740991`. Reject negative zero (`Object.is(value,-0)`), fraction, non-number, non-finite, or overflow before canonicalization. No decimal string or JSON BigInt encoding is allowed. Tuple encoders convert a validated SafeU64 losslessly to unsigned `u64be`; they never accept a wider value. Conserved quantities are JSON integer numbers `0..2147483647`; signed deltas/scores are `-2147483648..2147483647` with checked overflow. Counts framed as `u32be` are JSON integers `0..4294967295`. The published 0/1 JSON vectors therefore remain normative, and boundary vectors must cover every maximum plus rejected maximum+1.

The only hash preimage grammar is `tuple(tag, fields)`: ASCII `EONFOLK-TUPLE-v2`, zero byte, then tag and each field as `u32be(byteLength)||bytes`. Schema fixes field type/order; NFC strings use UTF-8, counters/revisions u64be, counts u32be, and hashes/seeds raw bytes. ## Durable-before-visible protocol

Before any command, `commitGenesis` idempotently creates the hashed manifest, verified genesis snapshot, run/region head/fence, and empty batch/event/decision/receipt stores in one transaction. Same run/same manifest retry returns the existing result; same run/different hash rejects. Crash injection proves either no run or the complete bound genesis. Every later operation rejects an absent/mismatched manifest, run, region, or version.

For every command:

1. read durable head/receipt;
2. prepare immutable accepted/rejected transition without installing it;
3. in one IndexedDB transaction verify manifest/run/region, prior state/world head, fencing and decision references; write the complete accepted `WorldBatchHeader` plus 1–32 state-hash-chained events; write accepted/rejected receipt plus associated hashed consequential-decision record; and advance revision/state/world head exactly once only for acceptance;
4. wait for commit;
5. install the post-state only if returned head matches;
6. publish projections and acknowledge.

Crash before commit discards candidate; crash after commit reconstructs from durable head/receipt/decision record. Retry identical ID/fingerprint returns receipt. Same ID/different fingerprint rejects permanently. Writer transfer increments a monotonic fencing token checked on every append/snapshot but leaves canonical state/world head unchanged. Stale writers reject. Snapshot success is independent of batch/event/head/receipt/decision commit. A pre-command malformed/missing proposal may append only its idempotent hashed rejected cognitive record; identical decision ID/hash returns the record, same ID/different hash is `DECISION_ID_COLLISION`, and neither path can write a batch, event, receipt, snapshot, or head. Accepted command means 1–32 contiguous events and one revision advance: from prior revision `r`, every non-final event post-state keeps `r`, and only the final event post-state uses `r+1`; a one-event batch therefore changes revision in its sole post-state. Rejected/no-op means zero events and no revision/state/world-head/PRNG change.

Replay snapshot state includes every accepted event with `sequence <= baseSequence` plus the matching base world-head hash; event sequences begin at 1. The genesis snapshot has `baseSequence=0` and no domain event. Require `fromInclusive = baseSequence + 1` and `toExclusive = finalSequence + 1`, applying exactly sequences `fromInclusive <= sequence < toExclusive` and every covering batch header. Zero replay events therefore means `finalSequence=baseSequence`, `fromInclusive=toExclusive=baseSequence+1`, and unchanged state/world-head hashes. Replay loads the immutable Experiment Manifest but never a Brain/model as reducer input. Backup/export/import/restore/fork are absent in V1.
