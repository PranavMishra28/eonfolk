# Informal real-world feedback

Use this when a friend or coworker tries the local build without a full
scripted session. It is still not formal research. Do not promote these notes
into README claims.

Copy into `tmp/playtesting/Pxx-informal-YYYYMMDD.md`. Do not commit the copy.

```text
Participant: P__
Context: informal __-minute local demo
Prior exposure: none / other
Commit: ______________

Observed:
-

Quote:
- ""

Follow-up they asked:
-

Inference (mine, not theirs):
-

Interpretation (later):
-

Limitations:
- Friend or coworker of the maintainer
- Convenience sample
- Not blinded
- No return-session evidence unless one actually happened
```

A later “I might try it again” is not retention. A mechanical bug may become
an ordinary GitHub issue after you strip private detail.
